# نور | NOOR

تطبيق تعليمي تفاعلي للأطفال والأسرة، يجمع التعلم الإسلامي المبسط مع تنمية المهارات والعادات الإيجابية والألعاب والإنجازات، ضمن تجربة تتكيف مع عمر المتعلم وملفه.

> **الحالة الحالية:** تطوير NOOR 1.4 مستمر على فرع `fix/ci-source-archive` عبر Pull Request مفتوح. لا تعتبر التغييرات مدمجة في `main` قبل إتمام المراجعة والدمج.

## رؤية المنتج

نور مساحة تعلم آمنة ومحفزة تساعد الطفل على:
- بناء صلة محبة بالقرآن الكريم والعبادات والذكر.
- التعرف على السيرة النبوية والأنبياء والشخصيات الإسلامية.
- ممارسة الأخلاق والآداب في مواقف الحياة اليومية.
- تنمية القراءة واللغة والتفكير والمهارات الأساسية.
- التعلم باللعب والتحديات ومتابعة التقدم والإنجازات.
- التعلم وفق العمر والمرحلة والاهتمامات، لا وفق قوالب نمطية مرتبطة بالنوع.

## أقسام المحتوى

| القسم | نطاق المحتوى |
|---|---|
| القرآن الكريم | الاستماع والتلاوة والتدرج في الحفظ والتدبر الميسر |
| الصلاة والطهارة | التعرف على الصلوات والوضوء والاستعداد والخشوع |
| الأذكار | أذكار الحياة اليومية والصباح والمساء والتحقق من المصادر |
| الأخلاق والآداب | الصدق والرحمة والاحترام والتعاون والأمانة والسلامة الرقمية |
| السيرة النبوية | محطات السيرة والقيم المستفادة منها |
| الصحابة والشخصيات | نماذج من الرجال والنساء وإسهاماتهم |
| قصص الأنبياء | قصص قرآنية وقيم الصبر والتوكل والعفو والتفكر |
| الألعاب والتحديات | الذاكرة والترتيب والمنطق والملاحظة وأنشطة STEM |
| الإنجازات والشارات | الفضول والمثابرة والمبادرة والاحتفاء بالتقدم |
| المناهج الأسبوعية | مسارات تعليمية ومراجعة وأنشطة متدرجة |

## التدرج العمري

المواد الجديدة موزعة على ثلاث مراحل تجريبية:
- **3–5 سنوات:** الاستماع والصورة والتكرار والأنشطة القصيرة بمرافقة ولي الأمر.
- **6–8 سنوات:** القراءة المبسطة والاختيار والترتيب والتطبيق العملي.
- **9–12 سنة:** الفهم والتفكير والبحث والمشروعات الصغيرة والمسؤولية الرقمية.

هذه حدود إرشادية للمحتوى، وليست تقييماً لقدرات الطفل. يمكن لولي الأمر اختيار مستوى أسهل أو أصعب حسب احتياج المتعلم.

## المحتوى المضاف في دفعة 1.4

- استيراد 89 ملف بيانات JSON من مستودع المحتوى السابق مع إبقاء المصدر القديم دون تعديل.
- إضافة 9 مجموعات محتوى تحريرية جديدة، تضم **54 درساً/نشاطاً** موزعة على القرآن والصلاة والأذكار والأخلاق والسيرة والشخصيات والأنبياء والألعاب والإنجازات.
- ربط مجموعات المحتوى الجديدة بمكتبة نور وفداء، وإظهار قسم الإنجازات والشارات.
- الإبقاء على الملفات الأصلية المنقولة لأغراض المراجعة والتتبع.
- إضافة هوية كتاب مفتوح وهلال ونجمة، وملف شعار SVG وأيقونة Android محدثة.

الملفات التحريرية الجديدة موجودة في:
`legacy_content/assets/content/noor_*.json`

## مبادئ الجودة والمراجعة

- لا تُنسب آية أو حديث أو فضل تعبدي دون مرجع واضح يمكن مراجعته.
- مواد القرآن تشير إلى السورة والآيات، ويجب أن يكون نص المصحف والتلاوة من مصدر موثوق.
- موضوعات الفقه والعبادات تعريفية ومبسطة، ويُرجع في تفاصيل الأحكام إلى ولي الأمر أو معلم مؤهل والمصدر المعتمد للأسرة.
- لا تستخدم الأنشطة التخويف أو الإحراج أو مقارنة الأطفال بعضهم ببعض.
- لا يُطلب من الطفل نشر اسمه أو صورته أو موقعه أو أي بيانات خاصة.
- يراعى اختلاف سرعة التعلم والاحتياجات، مع إشراف بالغ في الأنشطة العملية.
- المحتوى التحريري الجديد يحتاج مراجعة تربوية وشرعية دورية قبل اعتباره منهجاً نهائياً.

## بنية المشروع

- `NOOR_Source.zip`: أرشيف مصدر التطبيق الأساسي المستخدم في خط بناء Android.
- `.github/workflows/build.yml`: سير عمل التحليل والاختبارات وبناء APK.
- `legacy_content/assets/content/`: ملفات JSON المنقولة والمجموعات التحريرية الجديدة.
- `noor_upgrade/lib/data/content/legacy_content.dart`: قارئ محتوى المكتبة.
- `noor_upgrade/lib/features/home/legacy_content_screen.dart`: شاشة مكتبة نور وفداء.
- `noor_upgrade/patch_noor.py`: طبقة تركيب التحديثات على مشروع Flutter الأساسي.

يتم نسخ محتوى `legacy_content/assets/content/` إلى حزمة أصول Flutter أثناء البناء، ثم تحميله محلياً داخل التطبيق. المكتبة الإضافية لا تستبدل كتالوج NOOR الأساسي أو ملفات المتعلمين أو سجل التقدم.

## البناء والتحقق

يتطلب البناء Flutter stable وAndroid SDK وJava 17، بالإضافة إلى أسرار توقيع Android المضبوطة في إعدادات GitHub Actions.

للبناء المحلي داخل مشروع Flutter المستخرج:

```bash
flutter pub get
dart format lib test
flutter analyze
flutter test
flutter build apk --release
```

ينتج ملف Android:
`build/app/outputs/flutter-apk/app-release.apk`

سير GitHub Actions ينفذ التحليل والاختبارات وبناء APK Release والتحقق من التوقيع قبل رفع artifact. الإصدار المستهدف APK فقط، وليس Android App Bundle (AAB).

## خارطة الطريق

1. توسيع وحدات كل قسم إلى وحدات تعليمية ودروس قصيرة ومراجعات واختبارات.
2. مراجعة النصوص الدينية ومراجعها بواسطة مختصين.
3. إضافة تسجيلات صوتية مرخصة ورسوم توضيحية أصلية مع نصوص بديلة.
4. ربط الأنشطة بنظام التقدم والنجوم والشارات دون مكافآت ضاغطة.
5. تطوير اختبارات تحديد المستوى ومسارات تعلم قابلة للتخصيص.
6. تحسين لوحة ولي الأمر وتقارير التقدم وإعدادات وقت الشاشة.
7. إضافة اختبارات آلية للتحقق من بنية JSON وصحة المراجع والأعمار وتفرد المعرفات.
